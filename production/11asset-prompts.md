## 1. 全局硬约束（写进每一条提示词）

| 约束 | 提示词写法 | 原因 |
|---|---|---|
| 正面视角 | `正面端坐，完全正对镜头` | 游戏为正视图，程序驱动动画 |
| 单帧 | 不画任何动作序列/多视角 | 敲击动画由程序旋转爪子实现 |
| 居中构图 | `角色居中，占画面高度 70%` | 便于统一缩放对齐 220×180 逻辑画布 |
| 纯色背景 | `纯白色背景（#FFFFFF），无阴影投射在背景上` | 便于批量抠图；模型不支持透明底时用白底交付 |
| 无出血 | 角色整体（含耳朵尾巴）完整落在画面内 | 画布外会被裁掉 |
| 光向统一 | `柔和顶部柔光` | 六张合成时光影必须同向 |
| 无文字 | `画面干净，无文字、无水印、无边框` | — |

**输出尺寸**：1024×1024（或模型最大方图）。交付后按画布统一缩放，不用你管。

## 2. 六风格提示词段（每条提示词 = 基础段 + 风格段）

### 2.1 基础段（六风格共用，替换 `{设定}` 为 §0 内容）

```
一只{物种}卡通角色吉祥物，{特征清单}，{性格}的表情，
正面端坐，双前爪搭在鼓面边缘（不必画鼓，爪子自然下垂搭在身前即可），
居中构图占画面高度 70%，纯白色背景，柔和顶部柔光，画面干净无文字无水印
```

### 2.2 六风格段（追加在基础段末尾）

**黏土软萌（clay）**
```
3D 软陶手工黏土质感，表面细腻指纹肌理，柔和哑光，边缘圆润无锐角，
暖色调治愈系，像手工黏土定格动画道具
```

**贴纸（sticker）**
```
扁平上色贴纸插画，主体带均匀白色粗描边轮廓，描边内侧一条细深色内描边，
色彩饱和明快，像一张可撕贴纸，无投影
```

**极简扁平（flat）**
```
极简扁平矢量插画，零描边零渐变零投影，仅用 4-5 种低饱和色块构成，
几何化简化造型，五官用最少的点与线表现，包豪斯简约气质
```

**手绘线稿（sketch）**
```
手绘钢笔线稿插画，深棕色墨水线条带轻微手绘抖动，
主体内部约 12% 透明度淡彩填充，腮红用斜线排线，像速写本插画，米白纸感
```

**Q 版厚描边（chibi）**
```
Q 版卡通，头身比 1.4:1 大头小身，深灰 9px 等宽粗描边，
眼睛又大又亮带两点高光，腮红明显，表情夸张可爱，日系卡通徽章插画
```

**剪纸分层（papercut）**
```
分层剪纸拼贴插画，像多层彩纸剪出后错位堆叠，边缘有撕纸毛边质感，
层与层之间明显错位投影，纸纤维纹理，立体剪纸工艺贺卡
```

### 2.3 一致性技巧（六张必须像同一个角色）

- **首选**：支持垫图的模型——先生成 clay 版，满意后将其作为参考图，逐张生成其余五风格
- **次选**：固定 seed，六条提示词只换风格段，其余字面完全一致
- 生成后自查：五官相对位置、配色比例、特征清单逐条对齐，对不上就重roll
- 色值允许风格化偏移（剪纸/线稿天然偏色），但主色色相家族不能跑

## 3. 部件拆分提示词（供直接抠件；抠不动就交完整图由我拆）

> 诚实提示：多数文生图模型直接生成"孤立部件"效果不稳定。
> 推荐流程：**§2 生成六张完整角色 → 交付给我拆层**。
> 以下提示词供模型能力较强（SD + ControlNet / 支持局部重绘）时使用。

**身体（body）**
```
只画{物种}的躯干整体剪影：含头部轮廓、耳朵、尾巴、背部特征（{物种特征}），
但不含眼睛、嘴巴、腮红、前爪，正面姿态，{风格段}，纯白背景
```

**脸（face）**
```
只画{物种}的脸部表情元素：两只眼睛、一个小嘴巴、两点腮红，
透明背景孤立元素，彼此间距按"眼距=头宽 40%、嘴在眼下方 25%"布局，{风格段}
```

**左爪（pawL）**
```
孤立的单只卡通小爪，圆钝短爪带三指垫，掌面朝下微倾 10 度，
像搭在鼓边的手势，{风格段}，透明背景，单独一个物体
```

**右爪（pawR）**
```
同上，镜像另一只，爪形与左爪完全一致（仅左右翻转）
```

**锚点标注**（每风格一张，拍概念图即可，不用精致）：
爪子根部在身体上的连接点位置（用红点标出）——程序以此点为轴旋转敲击。

## 4. 可选加料（非必需，有则更好）

| 内容 | 用途 |
|---|---|
| 闭眼用力表情版脸（face_blink） | 敲击瞬间的表情切换，有则效果翻倍 |
| 侧视/背面草图 | 供帽子适配与周边制作参考 |
| 专属帽子草图 | 当前帽子供猫/龙体型；新物种头型差异大时建议画专属款 |

## 5. 交付清单与命名

```
deliver/
  ref/character-sheet.png        ← 一张最终定稿设定图（全身正面）
  clay/  {物种}_clay.png         ← 六风格完整角色图（必交）
  sticker/{物种}_sticker.png
  flat/  {物种}_flat.png
  sketch/{物种}_sketch.png
  chibi/ {物种}_chibi.png
  papercut/{物种}_papercut.png
  parts/（可选，模型拆件成功才交）clay_{物种}_pawL.png 等

  palette.txt                    ← 主色/点缀色 HEX

```
