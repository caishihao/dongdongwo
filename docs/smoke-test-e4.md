| 检查点 | 预期 |

## 4. 存档 schema v4

存档：`%APPDATA%\BongoCatRemix\save.json`（信封 = SchemaVersion + CRC32 + PayloadJson，不变）。

**v4 新增字段**（v3 全部字段保留）：

| 字段 | 类型 | 含义 | v4 默认 |
|---|---|---|---|
| Coins | long | 金币余额（记账不可为负） | 0 |
| DailyTapCount | int | 当日有效敲击数（跨天重置，敲击产币封顶依据） | 0 |
| DailyCoinDate | string | 每日重置标记日 yyyy-MM-dd（字符串序比较，回拨不重置） | "" |
| IdleCoinAccumulator | double | 滴灌秒数余数（跨会话续接） | 0 |
| DropBucket | list&lt;long&gt; | 24h 滚动窗口掉落桶（墙钟 UTC ticks） | [] |
| LastChestTicks | long | 上次开箱时间戳（诊断） | 0 |
| ChestChargeSeconds | double | 免费宝箱充能秒数（封顶单箱值，开箱消耗） | 0 |

**迁移（ADR-004 规则 2 链式）**：v1 → v2 → v3 → v4 一链到底；DailyCoinDate 置空 → E4 首启按"当日首次启动"发 +50。负 Coins 手改防御收敛 0。未来更高版本仍"只读不写"拒绝。

## 5. economy.json 参数摘要（嵌入 App 程序集，与 items.json 同模式）

敲击 250 次/币、日上限 500 · 滴灌 120s/币 · 每日奖励 50 · 掉落 15min（50% 无 / 30% 金币包 15~35 / 20% 物品，品质权重 70/22/7/0.9/0.1%）· 宝箱充能 7200s=2h（wooden）· 三箱 150/600/2400（期望回收率 ≈93%/94%/84%，单测红线锁定 <100%）· 拆解价 10/40/150/600/2500 · 重复折算 60% · 掉落桶 40 件/24h。
非法值（权重和≠1、含 unique、未知品质、负价格、未知箱引用、折算率越界）一律 fail-fast 拒绝加载。

## 6. 已知边界与遗留

- economy.json 为嵌入资源：改参数需重编译（热调面板/dev 命令属 epics E4-S4 可选项，未做，需要时改 ExternalResource + 文件加载器即可）。
- 宝箱购买（金币买箱）、3合1升阶、拆解手动操作属 E5（04-exchange），本版金币只有收入没有支出。
- 按键宏"同键 1s >20 次该分钟不计产币"（GDD-02 §7）未单独实现，当前以日上限 500 + 去抖兜底。
- 掉落间隔重启重新起算（离线不累计，GDD-02 §5）；待机恢复 >10min 的心跳间隔不补算。
- 保底（连续 15 箱未出 epic+ 必出）、图鉴全收集补偿属 GDD-02 后续项，未纳入 E4 范围。
- 视觉验收依赖 §3 人工检查点；自动化覆盖构建/66 单测/日志。
