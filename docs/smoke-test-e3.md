# E3 烟雾测试说明（docs/smoke-test-e3.md）

> 适用范围：E3 —— 装扮与库存：items.json 数据驱动 12 件原创装扮、库存/装备（存档 v3）、猫换装热换绑、托盘"背包"入口、背包/图鉴窗口。
> 前置：E1 烟测（docs/smoke-test-e1.md）+ E2 烟测（docs/smoke-test-e2.md）各检查点保持有效；本文只写 E3 增量。

## 1. 构建

```powershell
cd D:\BongoCat
dotnet build BongoCatReplica.sln          # 预期：0 警告 0 错误
dotnet test                               # 预期：36/36 通过（CatDirector 4 + 托盘命令 9 + 存档迁移 6 + 物品目录 8 + 库存服务 9）
```

## 2. 启动 / 退出

```powershell
.\src\BongoCat.UI\bin\Debug\net8.0-windows\BongoCatRemix.exe
# 自动化烟测（保留自 E1）：
.\BongoCatRemix.exe --smoke-exit-ms=8000
```

首次以 E3 版本启动（旧 v2 存档自动迁移），日志 `%TEMP%\bongocat-remix.log` 应依次出现：

```
[Inventory] items.json 已载入：12 件物品
[Save] 迁移 v2 → v3：新增 OwnedItems / Equipped* / InventoryInitialized（默认空库存）
[Inventory] 首次启动：已授予 5 件新手装并默认装备 common 三件套
[Outfit] 换装应用 hat='hat_dev_cap' skin='skin_cream' bongos='bongos_wood'
[Tray] 托盘图标已创建（菜单：显示隐藏/背包/音量/静音/镜像/尺寸/退出）
```

**第二次启动幂等**：不再出现迁移日志与"首次启动"日志；`[Outfit] 换装应用` 按存档装备还原。

## 4. 托盘"背包" + 库存/图鉴窗口

- 托盘右键新增**背包**菜单项（位于"显示猫/隐藏猫"下方）→ 打开普通窗口（非置顶、可关闭、600×400、奶油底深棕描边）。
- **背包 Tab**：
  - 左栏槽位过滤（全部/帽子/皮肤/鼓），点选即时过滤网格；
  - 首启动应有 5 件：程序员鸭舌帽、画家贝雷帽、奶油小猫、橘子汽水、原木小鼓（角标 ×1 默认隐藏）；
  - 物品卡：左上**品质色点**（自设计色板：灰/绿/蓝/紫/橙/品红）、中部**矢量图标**（与猫身同源几何，无位图）、名称；
  - 点选物品卡 → 底栏显示名称 → **装备**（已装备项按钮禁用、卡片描边变品质色 + "已装备"角标）；已装备物品可**卸下**恢复默认。
- **图鉴 Tab**：12 格总表 + 顶部"收集进度：5 / 12"；已拥有显示彩色图标 + 名称 + "已获得"；**未拥有 7 件显示灰剪影 + "？？？" + "未获得"**（收集欲钩子）。
- 窗口开着时换装 → 猫与列表状态同步刷新（无需重开窗口）；关掉窗口再从托盘打开 → 状态保持。
- 桌宠窗口保持置顶穿透不受背包窗口影响（点背包窗口不会把猫顶到后面）。

## 5. 存档 schema v3

存档：`%APPDATA%\BongoCatRemix\save.json`（信封 = SchemaVersion + CRC32 + PayloadJson，不变）。

**v3 新增字段**（v2 全部字段保留）：

| 字段 | 类型 | 含义 | v3 默认 |
|---|---|---|---|
| OwnedItems | dict&lt;string,int&gt; | 库存（itemId → 数量；E3 全为 1，字典为 E4 重复掉落预留） | {} |
| EquippedHat | string | 装备中的帽子 id，空串 = 无帽 | "" |
| EquippedSkin | string | 装备中的皮肤 id，空串 = 原创基础皮肤 | "" |
| EquippedBongos | string | 装备中的鼓 id，空串 = 原创基础鼓色 | "" |
| InventoryInitialized | bool | 新手装授予幂等标记（不用"库存为空"判断，防清空误触发重复授予） | false |

**迁移（ADR-004 规则 2 链式）**：v1 → v2 → v3 一链到底；v2 存档首次被读到时日志出现
`[Save] 迁移 v2 → v3：…`，既有字段一律不动；已是 v3 幂等（不迁移、不重发、不重置装备）。
未来更高版本仍按"只读不写"拒绝。

**手改存档防御**：把 EquippedHat 改成目录中不存在的 id（或槽位不符的物品）→ 启动时日志
`[Inventory] 存档装备引用失效（EquippedHat=…），已卸下恢复默认`，不崩溃。

## 6. 已知边界与遗留

- E3 未含宝箱（E3-S4）与预设（E3-S6）——库存只进不出，数量恒 1（字典结构已为 E4 预留）。
- unique 品质暂无物品；装备规则仅"每槽互斥一件"（GDD-03 §5 未定义 unique 专属互斥，如需收紧补 ADR）。
- 图鉴"未获得"名称打码按 GDD-03 §7 实现；品质枚举的 emote/uitheme/consumable 槽位 E3 未开放（Equip 路径显式拒绝）。
- 物品图标为运行时 XAML Geometry 绘制（与主窗口同源工厂 CosmeticArt），无位图素材、零外部文件。
- 视觉验收（帽子对位/斑点位置）依赖人工检查 §3 检查点；自动化仅覆盖构建/单测/日志。
