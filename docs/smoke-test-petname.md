# 烟测：宠物取名（E9 / REPLICA-PETNAME）

> 目标：验证「首登取名 → 托盘改名 → 双端互见」全链路，且旧客户端/旧服务器不断连。
> 建议使用两个独立存档目录做双开（见文末），避免互相覆盖。

## 1. 首登取名
1. 删除（或备份）`%APPDATA%\BongoCatRemix\save.json` 与 `.bak`，启动 `BongoCatRemix.exe`。
2. 出现「选你的伙伴」窗口：
   - 物种/风格卡片下方有 **「给你的伙伴取个名字」** 输入框；
   - 默认显示当前物种默认名：猫猫 / 小恐龙 / 阿瓜；
3. 验证预填联动：切到「小恐龙」页签，未手动改名时输入框应变为「小恐龙」；切到「阿瓜」应变为「阿瓜」。
4. 输入自定义名（如 `布丁`）→「就决定它了」。
5. 打开 `%APPDATA%\BongoCatRemix\save.json`，确认：
   - 顶层 `SchemaVersion` = 11；
   - `PayloadJson` 内 `PetName` = 清洗后的名字，信封 `Checksum` 非 0（保存时已重算）。
6. 清空场景：重删存档再启动，把输入框清空后确认 → 存档 `PetName` 应为所选物种默认名。

## 2. 托盘重命名
1. 右键托盘图标 →「重命名」。
2. 弹出小对话框（与主界面同主题色），预填当前名字，提示「留空恢复默认名」。
3. 输入 `糯米团` → 保存。
4. 重新打开 `save.json`，`PetName` 应为 `糯米团`，且 `checksum` 随之变化（无校验报错）。
5. 输入超长/控制符（如 30 个汉字、或从别处粘贴带换行的文本）→ 保存后只保留前 12 字素且 UTF-8 ≤24B，无乱码。
6. 清空 → 保存 → 回退当前物种默认名。

## 3. 双端互见
1. 在服务器上启动中继（或使用已部署的旧版中继，**无需更新**）：
   `BongoCat.RelayServer.exe --port 9437`（实际参数以部署脚本为准）。
2. 机器 A 托盘「多人」：
   - 「我的名字」为只读回显（= `PetName`，如 `糯米团`）；
   - 填服务器地址 → 加入/创建房间 → 记下 6 位房间码。
3. 机器 B 同样加入该房间（其 `PetName` 如 `小恐龙`）。
4. 预期：
   - A 的远端猫窗口：B 的猫**头顶上方**出现半透明主题色名字牌「小恐龙」，字号 11；超长名字以省略号结尾；
   - B 的远端猫窗口：A 的名字牌「糯米团」；
   - 双方多人窗口成员列表显示：`#1 糯米团（我） · 猫猫`、`#2 小恐龙 · 小恐龙`（物种随对方 CatState 更新）。
5. 改名场景：
   - A 在房间内托盘改名为 `阿瓜二世`；A 本地成员列表立即变为新名；
   - B 的成员列表/名字牌**暂不变**（预期，协议无改名广播）；
   - A 离开房间再重新加入 → B 收到新名册，名字牌与成员列表更新为「阿瓜二世」。

## 4. 旧端兼容（旁路）
1. 新客户端 A 连接**旧版中继**：能正常加入、收发位置/敲击；名册名字显示为宠物名（旧中继透传 name）。
2. 旧客户端（改名前的构建）连接同一房间：
   - 旧端只把新客户端宠物名当普通显示名展示，**不崩溃、不断连**；
   - 新端收到旧端显示名（最长 48B）也能展示（超长按 24B/12 字素省略），空白/坏名回退物种默认名。
3. 旧存档迁移：用 v10 存档（无 `PetName`）启动 → 读档后 `PetName` 为当前物种默认名，金币/物品/赛季/联机配置不变。

## 5. 双开命令（本机）
```bat
set BONGOCAT_SAVE_DIR=%TEMP%\bongocat-petname-A
start "" BongoCatRemix.exe

set BONGOCAT_SAVE_DIR=%TEMP%\bongocat-petname-B
start "" BongoCatRemix.exe
```
（`BONGOCAT_SAVE_DIR` 为烟测专用存档目录覆盖，互不污染真实存档。）
