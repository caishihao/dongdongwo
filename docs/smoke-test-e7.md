## 2. 启动 / 退出

```powershell
.\src\BongoCat.UI\bin\Debug\net8.0-windows\BongoCatRemix.exe --smoke-exit-ms=8000
```

首次以 E7 版本启动（旧 v6 存档自动迁移），日志 `%TEMP%\bongocat-remix.log` 应依次出现：

```
[Save] 迁移 v6 → v7：新增 TutorialCompleted=false / TutorialStep=0 / UiThemeId=cream
[Theme] 已载入主题：奶油（cream）
[Tray] 托盘图标已创建（菜单：显示隐藏/背包/通行证/新手教程/主题/音量/静音/镜像/尺寸/退出）
[Tutorial] 开始教程（从步 0 续接）
[Tutorial] 气泡进入步 0
[App] 烟测定时退出触发

```

- **迁移语义**：老存档（v6）→ TutorialCompleted=false → 首次 E7 启动触发教程一次（新功能引导，
  E7 交接拍板）。金币/物品/图鉴/预设/赛季进度逐字段保留（2026-11-08 实机验证：金币 246 与掉落桶
  原样续档）。
- **教程非模态**：气泡出现期间后台经济/掉落照常跑（烟测窗口内掉落桶继续计数即证据）。

## 3. 视觉/交互检查点（主理人人工验收）

1. **教程步 0「敲敲看」**：气泡贴在猫右上方（跟随猫位置，拖猫不脱靶，250ms 心跳），敲任意键 3 次
   → 气泡切到步 1，日志 `[Tutorial] 步 0 完成：敲击 3 次`。
2. **教程步 1「拖拖看」**：按住猫拖动 ≥20px 松手 → 步 2；原地点击（<20px）不推进。
3. **教程步 2「找背包」**：气泡移到托盘方向（屏幕右下），出现"打开背包"直达按钮；点按钮或走托盘
   菜单打开背包 → 教程完成，气泡关闭，日志 `[Tutorial] 教程结束`。
4. **跳过/下一步**：气泡上"跳过教程"任意时刻可用 → 直接置完成；"下一步"逐级推进。
5. **重播**：托盘"新手教程" → 从步 0 重看；重播期间金币/库存/通行证/保底计数纹丝不动。
6. **主题三选一**：托盘"主题"子菜单（奶油/墨夜/青竹），勾选态与存档同步；切"墨夜" → 背包、
   通行证、教程气泡三个窗口**已开与后开**全部即时变深底浅字（DynamicResource 合并字典热替换，
   无需重启）；猫本体黏土配色不变（主题只作用于普通窗口）。
7. **主题持久化**：切墨夜后退出重进 → 日志 `[Theme] 已载入主题：墨夜（ink）`，仍是深色。
8. **防回退抽检**：透明猫无黑底（CompositionTarget.BackgroundColor）、点击不抢游戏焦点、
   位置/尺寸全程物理像素、教程气泡不挡猫点击（透明区域点击穿透）。

## 4. 已知边界（按 GDD-07 §7 设计口径）

- 教程中掉落/宝箱事件照常触发（非模态正反馈）；教程气泡 Topmost 但透明区域不挡点击。
- 教程中途退出/崩溃：按步骤粒度存进度，重启从当前步续接（日志"从步 N 续接"）。
- 主题资源缺失（手改存档 UiThemeId 为非法值）：回退默认奶油并写回修正，不白屏。
- ComboBox 等系统控件模板未随主题定制（V1 仅换肤不改布局，GDD-07 §8 开放问题 2 保持 V2 再议）。
