# E2 烟雾测试说明（docs/smoke-test-e2.md）

> 适用范围：E2 —— 托盘图标+右键菜单、音频设备热拔插恢复、空闲 CPU 证据、设置项持久化（存档 v2）、隐藏后再显示。
> 前置：E1 烟测（docs/smoke-test-e1.md）各检查点保持有效；本文只写 E2 增量。
> 环境：Windows 10 1607+ / .NET 8 / DWM 开启；托盘需要通知区域可用（远程桌面会话请确认"始终显示托盘图标"）。

## 1. 构建

```powershell
cd D:\BongoCat
dotnet build BongoCatReplica.sln          # 预期：0 警告 0 错误
dotnet test                               # 预期：18/18 通过（CatDirector 4 + 托盘命令 9 + 存档迁移 5）
```

## 2. 启动 / 退出

```powershell
.\src\BongoCat.UI\bin\Debug\net8.0-windows\BongoCatRemix.exe
# 自动化烟测（N 毫秒后优雅退出，等号连接，保留自 E1）：
.\BongoCatRemix.exe --smoke-exit-ms=8000
```

- 通知区应出现**原创简笔猫脸托盘图标**（运行时 DrawingVisual 绘制，无嵌入 ico 文件）。
- 退出方式（E2 起）：**托盘右键 → 退出**（唯一正式入口）；Ctrl+Alt+Q 热键保留为应急。
- 日志：`%TEMP%\bongocat-remix.log`。

## 3. 托盘菜单检查点

| 菜单项 | 检查点 |
|---|---|
| 显示猫/隐藏猫 | 隐藏后窗口消失；再显示时**回到上次位置**（按存档比例 + 当前物理尺寸重算，切换过尺寸档位也对位） |
| 音量（滑条） | 拖动即时变响/变轻；停手约 0.5s 后落盘（防抖，拖动期间不写盘） |
| 静音 | 勾选后敲键盘无声音；取消后恢复原音量；重启后勾选态保持 |
| 水平镜像 | 勾选后猫左右翻转；重启后保持 |
| 猫尺寸 | 75% / 100% / 150% 单选；切换即时生效；**放大到 150% 时若贴近屏幕右/下缘，窗口整体被 clamp 回工作区内不出屏**；重启后档位保持 |
| 退出 | 托盘图标消失（无残影）；进程退出；重启后位置与全部设置一致 |

日志应出现：`[Tray] 托盘图标已创建（菜单：…）`；尺寸切换时 `[Window] 尺寸档位 → 150%，物理矩形 (…)…`。

## 4. 设置持久化（存档 schema v2）

存档：`%APPDATA%\BongoCatRemix\save.json`（信封 = SchemaVersion + CRC32 + PayloadJson）。

**v2 字段说明**（相对 v1 新增 `WindowScale`，其余不变）：

| 字段 | 类型 | 含义 | v2 默认 |
|---|---|---|---|
| SchemaVersion | int | 版本号，E2 起 **2** | 2 |
| CatPositionRelX / Y | double | 猫窗口左上角 / 主屏工作区比例 0~1 | 0.45 / 0.32 |
| CatMirrored | bool | 水平镜像 | false |
| MasterVolume | float | 主音量 0~1 | 1.0 |
| Muted | bool | 静音 | false |
| **WindowScale** | double | 窗口缩放档位（相对基准 130×110 DIP），合法值 0.75 / 1.0 / 1.5 | 1.0 |

**迁移（ADR-004 规则 2）**：v1 存档首次被新版读到时自动升级——日志出现
`[Save] 迁移 v1 → v2：新增 WindowScale=1.0`，既有字段一律不动；已是 v2 的存档幂等（不再出现迁移日志）。
非法档位（如手改成 2.7）无论来源版本收敛为 1.0；未来更高版本仍按"只读不写"拒绝。

## 5. 空闲 CPU 证据（epics E1-S3 后置项，代码内自证）

`KeyPollingService` 轮询线程每 60 秒向日志输出一行：

```
[KeyPolling][CPU] 近60s：轮询 N 次（活动档 A / 空闲档 I），上升沿事件 E 个，平均间隔 X.XXms
```

**解读方法**：

1. 启动应用后**不打字**静置 ≥ 70 秒，读一行统计。预期：`活动档 0`（10s 无按键后已降频）、
   `平均间隔 ≈ 50ms`（即每秒约 20 次轮询，一行 ≈ 1200 次）——这就是空闲态的全部 CPU 行为：
   一条后台线程每 50ms 扫一遍 VK 表后 Sleep，量级远低于 1%（单核万分之几）。
2. 持续打字 ≥ 70 秒再读一行。预期：`活动档` 占绝大多数、`平均间隔 ≈ 8~10ms`，上升沿事件数 ≈ 键击数
   （30ms 去抖在 Director 层，轮询层每键 1 个上升沿）。
3. 若空闲档轮询次数异常膨胀（平均间隔远小于 50ms），说明有按键活动反复把轮询拉回活动档——
   检查是否有后台程序在注入按键。

注意：`--smoke-exit-ms` 短烟测（< 70s）**不会**输出 CPU 统计行，属正常；要看这行请手动静置运行。

## 6. 音频设备热拔插恢复（epics E2-S4）

- 播放中拔掉当前默认音频设备（USB 耳机/蓝牙）：下一个按键可能丢失一两个音（重建窗口），
  随后日志出现 `[Audio] 输出设备异常：…，开始重建（E2-S4 热拔插恢复）` →
  `[Audio] WaveOutEvent 已重建，后续音效走新默认设备`，之后敲鼓声从**新的默认设备**（扬声器）出。
- 全部音频设备拔空的极端情形：日志出现指数退避重试记录（1s/2s/4s… 封顶 30s，最多 6 次）；
  设备接回后若重试次数未耗尽即自动恢复，否则重启应用恢复（日志有明示）。
- 事件不丢：重建只换输出端（WaveOutEvent），混音器/音量节点/音色对象池全生命周期复用，
  重建期间 Play 正常入队不抛异常。

## 7. 已知边界与遗留

- 隐藏猫期间轮询/动画继续运行（E1-S5 的"隐藏时暂停动画"在 E2 未实现，视觉不可见、CPU 影响可忽略）。
- 托盘双击 = 显示/隐藏猫快捷切换。
- 音量滑条落盘防抖 400ms；若拖动中强杀进程，最后 0.5s 内的音量变化不入档（可接受）。
