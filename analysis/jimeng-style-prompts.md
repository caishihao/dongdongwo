# 即梦 Seedream 文生图：敲鼓猫六风格候选生成指南

## 使用策略：锁底座、换风格

六张图必须**共用同一段主体描述（底座）**，只替换风格段——否则生成结果姿态、构图、配色都漂移，没法横向对比。

两种做法（推荐 B）：
- **A. 纯文生图**：直接粘贴下面的整段提示词
- **B. 参考图生图**：先把游戏内截图（或任意一张已满意的渲染图）作为参考图上传，用"参考主体/人物"模式锁定**造型和姿势**，提示词只写风格段+底座，一致性最好

## 通用底座（每条提示词都以下面这段开头）

```
一只奶油色的小猫，正面朝向镜头端坐，两只前爪放在一面小邦戈鼓上敲鼓，
粉色内耳，圆润大眼睛，头顶戴一顶红色圣诞帽，
画面中央特写构图，纯色浅米色背景，居中对称，光照均匀，
高清插画，细节清晰，画面干净无文字无水印
```

## 六条风格段（接在底座之后）

### 1. 黏土软萌风
```
黏土手工质感，3D 软陶捏制效果，表面有细腻指纹肌理和柔和哑光，
边缘圆润无锐角，柔和的顶部柔光与轻微环境光遮蔽阴影，
暖色调，治愈系，整体像手工黏土定格动画道具
```

### 2. 贴纸风
```
扁平贴纸插画风格，主体带 5px 均匀白色粗描边，
底部投下椭圆形柔和阴影，色彩饱和明快，
像一张可以撕下来贴的贴纸，轮廓完整闭合，背景保持纯色
```

### 3. 极简扁平风
```
极简扁平矢量插画风格，零描边零渐变零投影，
仅用 4-5 种低饱和色块构成，几何化简化造型，
五官用最少的点与线条表现，大量留白，包豪斯简约气质
```

### 4. 手绘线稿风
```
手绘钢笔线稿风格，深棕色墨水线条带轻微手绘抖动感，
纸张米白色底，主体内部仅有 12% 透明度的淡彩填充，
腮红用斜线排线表现，整体像速写本上的插画
```

### 5. Q版厚描边风
```
Q 版卡通风格，头身比 1.4:1 大头小身，
9px 深灰色粗描边，眼睛又大又亮带两点高光，
腮红明显，表情夸张可爱，色彩鲜艳，
像日系卡通集换式徽章插画
```

### 6. 剪纸分层风
```
分层剪纸拼贴风格，像多层彩纸剪出后错位堆叠而成，
边缘有撕纸毛边质感，层与层之间有明显的错位投影，
纸纤维纹理可见，色彩为带手作感的纸浆色，
像立体剪纸工艺贺卡
```

## 即梦操作要点

1. **画幅选 1:1 或 4:3**（对应游戏里的窗口比例，预览最接近实机效果）
2. **参考图模式**（做法 B）：上传截图后选"参考主体"而不是"参考风格"——我们要锁造型，风格由文字控制
3. 每个风格**生成 4 张挑 1 张**：AI 对"描边粗细""头身比"这类量化描述执行有波动，多抽卡
4. 六个风格段都生成完后，把六张图放在一起对比**姿态是否一致**——漂移严重的用参考图模式重抽
5. 生成结果仅作**风格候选的视觉参照**，正式制作仍以游戏内矢量渲染为准（AI 图不能直接当素材，版权与一致性都不适合）

## 进阶：想微调某只

生成后如果某风格"接近但不满意"，用即梦的局部重绘/消除笔修，或在原提示词后追加修正句，例如：
- Q 版头不够大 → 追加 `头部再放大，接近二头身`
- 贴纸描边太粗 → 追加 `描边更细更均匀`
- 剪纸层次不够 → 追加 `增加 2-3 层可见的纸片错位`
