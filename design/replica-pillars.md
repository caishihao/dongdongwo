# 复刻支柱与 MDA 分析 — BongoCat 复刻版（代号：DeskCat Beat）

> 依据 `analysis/bongocat-analysis.md` 的机制拆解，只复刻**机制**，素材/数值/文案全部原创。
> 平台：C# WPF（.NET 8），Windows；范围 V1-V3 全量。

## 一、设计支柱（Design Pillars）

1. **「三秒心动」——零门槛的即时反馈**
   任何按键 ≤ 50ms 内转化为视觉（爪子敲击）+ 听觉（鼓点）反馈。桌宠永远在那里、永远在回应，不开菜单、不读教程也能立刻感到"它在跟我互动"。

2. **「陪伴中收集」——被动在场也持续成长**
   玩家不需要"玩游戏"：打字、摸鱼、挂机的每一分钟都在积累金币与掉落。收集的推进节奏贴近真实日程（小时级可见进度，周级集齐一套），而不是要求专注 session。

3. **「我的桌面我的猫」——强个性化与所有权**
   帽/皮肤/鼓/表情/UI 主题全套装扮 + 图鉴 + 预设，玩家对猫的外观拥有"养成感"与"炫耀点"（多人摆放时尤其明显）。一切稀有度都服务于表达，而非 Pay-to-Win（本项目无任何真实货币）。

**支柱漂移红线**：任何新增机制若不服务以上三条（如强竞技、强制任务、打断式弹窗），一律拒绝。

## 二、MDA 分析

### 机制（Mechanics）
- 全局键盘钩子：任意按键 → 左右爪交替敲击（单键按下即触发，无连击判定）。
- 敲击动画：按下瞬间爪落 → 回弹（可调 ~100-160ms），呼吸浮动 idle 动画。
- 鼓点音效：左/右爪对应高低音，随机轮换 2-3 个变体防重复感。
- 窗口：透明置顶、可拖动、位置记忆（相对屏幕比例存储）、越界回中。
- 经济：敲击/在线时长 → 金币；定时掉落 → 物品/金币；金币 → 宝箱 → 品质抽取。
- 收集：6 槽位（帽/皮肤/鼓/表情/UI主题/消耗品）× 6 品质（common→unique）。
- 合成：同品质 3 合 1 升阶；重复物品自动折算金币。
- 赛季：本地赛季配置 JSON，敲击量 + 每日任务 → 等级 → 双轨奖励。
- 多人：局域网 WebSocket，猫摆放同步 + 敲击同步 + 表情互发。

### 动态（Dynamics）
- **节奏陪伴**：玩家打字 → 猫随打字节奏敲鼓 → 无意中形成"打字 BGM"，工作/聊天本身被游戏化。
- **收集循环**：挂机积累 → 惊喜开箱 → 换装展示 → 触发"下一个目标"（图鉴缺口）。
- **合成抉择**：3 合 1 是否值得？留低阶凑合成 vs 直接拆金币，形成持续微决策。
- **桌面社交**：局域网内同事/家人把猫摆成一排，互发表情，成为办公室小玩具。
- **赛季节律**：每赛季（~6 周）刷新目标，老玩家回归理由。

### 美学（Aesthetics）
- **表达（Expression）+ 探索（Discovery）**：核心 Bartle 倾向，配合 Killers 的展示欲（多人摆放）。
- 自我决定论对齐：自主（装扮自由）、胜任（图鉴完成度、赛季等级）、关联（局域网共建桌面场景）。
- 情感基调：轻松、萌、低压力——禁止任何焦虑设计（倒计时逼氪、每日强制打卡）。

## 三、与原作的机制对照与原创决策

| 原作机制 | 复刻决策 |
|---|---|
| Unity + Steam Inventory | WPF + 本地 JSON 存档（`%AppData%/DeskCatBeat/`） |
| Steam 多人大厅/Battle Royale | 局域网 WebSocket 摆放模式（不做 BR，超范围） |
| 挂机掉落（时长心跳） | 保留机制，数值全原创（见 02-economy） |
| 6 品质色值（#B0B0B0 等） | 机制保留，**配色全新设计**（见素材清单） |
| 支持者 DLC / 联动活动 / 投票 | 不复刻（平台绑定，无本地价值） |
| PawPass 赛季 | 保留结构，高级轨用游戏内金币解锁，无真实支付 |

## 四、范围分层与验收锚点

- **MVP**：敲击+音效+拖动+记忆。验收：任意按键 50ms 内出反馈；重启后位置还原；CPU 空闲 <1%。
- **V1 经济**：闭环可跑 2 周不崩（数值见 02）；图鉴可 100% 完成且路径明确。
- **V2**：合成/预设/表情/主题/教程全部可用，教程 3 步内跳过。
- **V3**：通行证本地赛季可配置热更；4 台机器局域网摆放同步 <200ms 延迟。

## 五、开放问题（需主理人/用户拍板）
1. 猫形象风格：像素（8-bit 感）还是扁平矢量？影响全部素材规格。
2. 敲击音效基调：真实邦戈鼓采样 vs 芯片音（chiptune）合成？
3. 通行证高级轨用金币解锁（当前设计）还是纯免费轨？前者保留目标感，后者最简。
4. 多人模式 V3 是否包含"互赠礼物"？建议 MVP 先砍掉，协议留字段。
