# GDD-09 物种系统：原创小恐龙（Species: Dino）

> 依赖：GDD-01（六部件渲染层与锚点）、GDD-03（槽位模型）、GDD-06（CAT_STATE 同步）、GDD-07（教程时序）、GDD-08（风格/装扮正交模型）。
> 范围：第二个物种"小恐龙"作为独立角色，参与全部玩法（风格/装扮/多人）；开场物种×风格选择器；协议与存档升级。
> 状态：V1 设计规格（待主理人与用户审批）。

## ⚠️ 0. IP 红线（最显眼位置，先于一切设计）

用户提供的参考"奶龙"是**受保护商业 IP**。进游戏的必须是**原创小恐龙**：

- **允许**："黄色圆润小生物"这一通用类型气质（黄色、圆胖、矮墩墩可爱）。
- **禁止**复刻奶龙的：五官布局（眼-腮红-嘴的位置关系）、头身比例关系、腹部斑形的专属组合。三者**组合出现即视为侵权**，单独出现_generic 元素不构成。
- 交付自检：美术管线交付恐龙资产时，必须并排官方参考图核对 §6 差异清单，**任一"禁用组合"命中即打回**，不放行。

本文所有恐龙特征均为自有设计，与奶龙的区分依据见 §6。

## 1. 物种模型：三层正交

```
渲染管线 v2：StyleRenderer(styleId) + SpeciesShapeProvider(speciesId) + OutfitAssets(itemIds) → 六部件帧
              （怎么画）                （什么形体——新层）        （画什么）
```

| 层 | 回答 | 数据源 | 变更频率 |
|---|---|---|---|
| 风格 Style | 用什么笔法画（描边/配色逻辑/动画手感） | styles.json | 换风格即时切 |
| **物种 Species（新）** | 什么形体（剪影/部件几何/锚点偏移/专属静态特征） | **species.json（新增）** | 换物种即时切 |
| 装扮 Outfit | 画的内容（帽/皮肤/鼓） | items.json | 换装即时切 |

**物种与装扮的关系（结论）**：
- **帽子**：几何数据全物种共用（沿用 GDD-08 §1.2"共用一套帽子形状"）。恐龙帽戴在**双角之间**——物种层提供 `hatAnchorOffsetY` 增量（见 §2.3），帽子位图本身零改动；帽 Z 序在角之上，角被帽压住属于预期萌点。
- **皮肤**：内容层四色板（奶油/橘/灰/奶牛）**恐龙可直接装备**（GDD-08 §1.1 转译规则不变）；新增**恐龙默认专属皮肤** `dino_default`（柚黄+青绿点缀，见 §2.2）写入 items.json，仅当物种=恐龙时可装备（items.json 增加 `speciesOnly` 字段）。猫玩家不可穿 dino_default，龙玩家可穿四色板（棘刺/角/尾尖的青绿点缀**固定于形体层**，不随皮肤色板变——保证任何皮肤下龙都有辨识度）。
- **鼓**：**完全不变**。鼓是玩法道具不是物种特征，敲击判定、音画同步、bongos 槽位零改动。
- 皮肤/鼓在龙身上的渲染 = 同一几何数据换形体承载，不做第二套装扮库。

## 2. 原创小恐龙形体规格

### 2.1 总则
- 整体渲染尺寸与猫一致：**220×180 逻辑px**，DPI 缩放、呼吸浮动、镜像、拖动规则全部沿用 GDD-01。
- **六槽位全部复用**：body / face / bongos / pawL / pawR / hat。恐龙的三个专属特征（背棘列/双角/尾）**归属物种形体层**，作为静态元素**烘焙进 body 部件位图**（它们与身体无相对运动，不需要独立动画层）——这是图层预算的关键决策。
- 敲击动画参数（压深/回弹/挤压/旋转）**逐风格沿用 GDD-08 §2.6，恐龙不另调**：爪与鼓的世界坐标锚点不变（Q版先例，GDD-08 §2.4），音画同步逻辑零改动；同风格下猫龙手感一致，多人同屏不违和。
- 窗口尺寸不变 → 多人排布算法（GDD-06 §5）、槽位协商、窗体高度计算全部零改动。

### 2.2 形体定义（部件逐项）
| 部件 | 猫（现状） | 恐龙（新） |
|---|---|---|
| body | 坐姿胖梯形身 | 坐姿**胖水滴身**（重心更靠后、底部更宽），背中线上**5 枚圆钝棘刺**（半圆凸起，间距均匀，由大到小向尾排），右后方伸出**短圆三角尾**（尾尖钝圆）；头顶**两根圆钝小角**（左右对称，短圆柱+圆头） |
| face | 猫脸：点眼/圈眼/w 嘴 | **圆钝吻部**（口鼻区椭圆微凸出 4px）、吻上**两个 2px 鼻孔点**；**豆豆眼**（实心圆，无猫的高光双点结构）；**短弧线嘴**（一笔微笑弧，非 w 形）；腮红沿用各风格语言 |
| bongos | 面前一对面鼓 | **不变**，同一几何同一锚点 |
| pawL/pawR | 胶囊爪 | **圆钝短爪**（略短 8%、三指垫轮廓），锚点世界坐标不变 |
| hat | 头顶锚点 | 同一帽子几何，锚点见 2.3 |

### 2.3 锚点与图层核算
- **hat 锚点**：物种层定义 `hatAnchorOffsetY = -14px`（相对猫锚点上移，落位于双角之间），与风格层 `hatAnchorOffsetY`（styles.json，如 Q版 -10）**相加**合成。验证点：Q版龙 = -10 + -14 = -24，需美术出图确认帽不穿角（开放问题 1）。
- **图层数核算（每风格 ≤8，ADR-003）**：

| 风格 | 猫层数 | 龙层数 | 说明 |
|---|---|---|---|
| 黏土/贴纸/扁平/线稿/Q版 | 6 | **6** | 棘刺/角/尾全部烘焙进 body 位图，零新增 |
| 剪纸 | 6–7 | **7–8** | 恐龙剪纸的棘刺列改用**独立色纸小条**（+1 层，剪纸"分层即逐帧"语言的自然表达）；最坏 = 6 基础 + 棘刺条 1 + 奶牛斑块纸片 1 = **8 ≤ 8**，预算内 |
- 裁剪预案：若美术实测剪纸龙视觉过碎，棘刺条降级为烘焙进 body 纸层（撕纸边烘焙路径），回到 6–7 层。

### 2.4 恐龙默认皮肤（物种专属色板）
```
dino_default（items.json，speciesOnly: dino）：
  身体   柚黄 #EFD35D（刻意偏暖绿相，与参考 IP 的正黄拉开色相）
  棘刺/角尖/尾尖  青绿 #2EA98F（物种固定点缀，三处呼应，自有特征）
  吻部/腹侧   米白 #F7F1E3
  爪/内耳   柚黄加深 8%（#D9BC4F，沿用 GDD-08 §2.2 明度差规则）
```

### 2.5 六风格 × 恐龙要点（差异于猫处，其余沿用 GDD-08 §2）
| 风格 | 恐龙版要点 |
|---|---|
| 黏土 | 基线形体直出；棘刺/角做黏土捏塑圆角，青绿点缀为第二块黏土色 |
| 贴纸 | 整体（含棘刺/角/尾）白描边 5px 一起剪出；棘刺间隙 2px 白边与部件间隙一致 |
| 扁平 | 棘刺 = 5 个纯色半圆几何；角 = 2 个圆头短柱；**无描边**，靠 8% 明度差分部件 |
| 线稿 | 棘刺/角/尾只描线不填（skinFillOpacity 0.12 同规则）；青绿点缀在 <120px 缩放时省略（线宽加粗阈值同款处理，防小尺寸糊） |
| Q版 | 头身比放大到 1.3:1（比猫 Q版 1.4:1 略收，保龙形辨识）；角变短圆墩；描边 9px 全部件 |
| 剪纸 | 棘刺列 = 独立色纸条（见 2.3）；角/尾仍烘焙；错位阴影自然表达背棘起伏 |

## 3. 开场选择器改版（第 0 步：物种 × 风格）

### 3.1 交互方案（结论）
- 面板标题改"选你的伙伴"。**顶部两个物种页签：猫 🐱 / 恐龙 🦖**（页签内嵌该物种当前风格缩略剪影）；**下方 6 张风格卡不变**，卡片预览实时切换为"当前页签物种 × 该风格"的 idle 微动画（呼吸 0.5× + 每 4s 轻敲，参数沿用 GDD-08 §3.2）。
- 选择状态 = **(species, style) 组合**：切页签不清空风格选择（对比成本是"同一风格下的猫 vs 龙"）；确认按钮"就决定它了"一次写入两个字段。
- 跳过 = **(cat, clay)**，与 GDD-07 教程时序完全兼容（选完进第 1 步，教程全程看到自己的伙伴）。
- 布局：面板从 6 卡并排变为"页签行 + 6 卡行"，总高约 +64px；高 DPI/对比度要求沿用 GDD-07。

### 3.2 触发条件与时序
- 触发 = `TutorialCompleted == false 且 StyleChosen == false`（**复用现有双标记，不新增 SpeciesChosen**——物种与风格在选择器中一次同时确定，一个标记即够）。
- v10 迁移刻意把老玩家 `CatStyleId` 清空 + `StyleChosen=false` → 全体老玩家重看一次升级版第 0 步（顺便获得选龙机会），与 v8→v9 迁移策略同构。

### 3.3 后续更换入口（托盘）
"形象"子菜单升级为**两个并列子菜单**：
```
形象 ▸ 物种 ▸ （猫 ✓ / 恐龙）
     ▸ 风格 ▸ （黏土 ✓ / 贴纸 / 扁平 / 线稿 / Q版 / 剪纸）
```
- 勾选态单一数据源 = 存档 `SpeciesId` / `CatStyleId`，与现状同构；切换即时生效，互不清空装扮。
- 背包窗口"形象"页留 V2 不动（与 GDD-08 §3.3 结论一致）。
- 多人场景：本机换物种 → CAT_STATE 重发（与 outfit/style 变更同通道同节流），远端窗口立即显示龙。

## 4. 多人协议方案（结论）

沿用 GDD-06 JSON 协议 + GDD-08 的"payload 升小版本、旧字段不解析即忽略"先例：

- **CAT_STATE payload 追加整数字段 `"species"`**（`0=cat, 1=dino`，与 style 的字节枚举同构，写进 Protocol 常量表 `SpeciesByte`）。帧结构、消息类型表完全不变，`payloadVersion` +1。
- 新客户端收**旧** payload（无 species 字段）→ 默认 `cat` 渲染，会话正常。
- 旧客户端收**新** payload → 按既有规则忽略未知字段，**回退渲染为猫**（同 styleId），不报错不断连。龙玩家在旧客户端眼中是"一只同风格的猫"——可接受的降级，不阻塞会话。
- 非法值（species >1 或非整数）→ 回退 cat + 记日志（沿用 GDD-08 §4 防伪造规则），不断连接。
- 远端龙渲染 = 对端 speciesId + styleId + outfit id，StyleRenderer 复用本地实现，无新资产下发。WELCOME 成员快照的 members[] 同步加 species 字段，供成员列表图标显示。

## 5. 存档方案（v9 → v10）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `SpeciesId` | string | `"cat"` | 枚举：`"cat"` / `"dino"`；空串按 `"cat"` 解析（兼容防御） |
| `SpeciesChosen` | **不新增** | — | 与 `StyleChosen` 合并时序：选择器一次写两字段，`StyleChosen=true` 即代表"物种+风格均已选定" |

- 迁移 `v9 → v10`：`SpeciesId = "cat"`（默认）；同时 `CatStyleId = ""`、`StyleChosen = false`（触发一次新版选择器，见 §3.2）。
- 迁移 `v8 → v10`（跳版）：同 v9 路径再叠加 SpeciesId 默认。
- 加载校验：`SpeciesId` 不在枚举内 → 回退 `"cat"` + 记日志 + 托盘气泡一次（沿用 GDD-08 §6.1 模式）。
- 原子写入沿用 E1-S8；第 0 步期间崩溃重启跳过第 0 步（GDD-08 §6.2 语义不变）。

## 7. 边界与不做（V1 范围）

| 项 | 结论 |
|---|---|
| 恐龙语音/音效 | **不做**。敲鼓音效猫龙完全共用（左低右高 2-3 变体随机，GDD-01）；恐龙无叫声（猫也无） |
| 恐龙专属装扮（龙角帽/龙翼背饰等） | **V2**。V1 全量共用猫装扮库（帽子几何共用前提，GDD-08 §1.2）；items.json 的 `speciesOnly` 字段先落位，V2 直接复用 |
| 第三物种 | ~~不做~~ → **阿瓜已上线（§10，sprite 渲染路径）**。`SpeciesByte` 枚举 0–2，3–15 预留 |
| 物种进经济 | **不进**。与风格同轴：物种是表达轴非稀缺轴，猫/龙全免费自选，不进宝箱/通行证/交易（GDD-08 §5 同款论证） |
| 换物种清装扮 | **不清**。物种与装扮解耦（§1）；某装扮在龙形体下渲染异常 → 降级该槽默认外观（沿用 GDD-08 §6.4 模式） |

## 8. 边界情况

1. **存档 SpeciesId 非法/损坏** → 回退 cat + 日志 + 气泡一次（§5）。
2. **远端 species 字段非法** → 回退 cat 渲染 + 日志，会话不断（§4）。
3. **旧客户端收到恐龙状态** → 渲染为同风格猫，其他玩家无感（§4）。
4. **帽子与双角穿插**（极端帽子几何）→ 锚点 -14px 为默认；美术验收逐帽检查，个别帽型可在 items.json 加 per-item `hatAnchorOffsetY` 微调（数据驱动，零代码）。
5. **线稿风恐龙 <120px 缩放** → 青绿点缀省略 + 线宽加粗（与 GDD-08 §2.3 阈值同规则）。
6. **选择器在低配机首启**（2 物种 × 6 风格 = 12 个预览）→ 沿用 GDD-08 §7.1 实测结论：超阈值则只动画选中页签的 6 卡，另一页签静态剪影。
7. **v10 存档被旧版本程序读取**：未知字段忽略，SpeciesId 丢失 → 旧程序按 v9 语义走（猫），不损坏原字段。

## 9. 开放问题（交程基岩/林绘澄确认）

1. Q版龙 hat 锚点合成 -24px 后，帽位图是否超出 220×180 窗体上缘——需实测；若是，窗体上缘留白 +16px 一次到位（窗体高度属全局改动，需工程评估远端猫窗体影响）。
2. 恐龙形体位图由美术管线按"每风格 × 每部件"交付（6 风格 × 6 部件 × 2-4 帧），资产量 ≈ 猫的 2 倍——排期需与林绘澄确认是否按"黏土+贴纸先行、其余风格跟进"分批上线（协议/存档一次到位，风格覆盖分批不冲突）。
3. 远端猫窗体若是按内容自适应（GDD-08 §7.2 未决），龙形体剪影更宽（尾部），窗体宽度需同步验证。

## 10. 第三物种"阿瓜"（sprite 位图渲染路径，设计侧交接格式）

> 本节为 GDD-09 §7"第三物种不做"的修订：阿瓜（agua）已按**位图 sprite 渲染路径**上线。
> 阿瓜为用户自有 AI 生成角色（黄色小恐龙形、绿眼、奶油肚、棕色三指小爪），走与矢量物种
> （cat/dino = StyleArt 程序化矢量）**正交的第二条渲染管线**。

### 10.1 渲染路径模型（vector vs sprite）

| 维度 | vector（cat/dino） | sprite（agua） |
|---|---|---|
| 形体来源 | StyleArt 程序化矢量模板 | 位图 sprite（嵌入资源 PNG） |
| 表情层 | PartFace 独立层 | **脸烘焙进 body，v1 无表情切换**（已知简化） |
| 邦戈鼓 | 各风格程序化鼓层 | **双鼓不拆，共用程序化鼓层**（按当前风格配色，StyleArt.BuildSpriteBongos） |
| 装扮换绑 | SkinTargets 真实形状换色 | 哑形状（契约字段非空、涂色无视觉效应）；帽子照常矢量叠画（跨路径混排） |
| 帽锚 | species.json `hatAnchorOffsetY` 增量 | anchors.json `hatAnchor` 绝对锚（220×180 逻辑坐标） |

渲染序与矢量物种一致：body sprite（居中位）→ 程序化鼓层 → pawL/pawR sprite（绕爪轴旋转压深）→ hat。
敲击动画零改动复用 CatTapAnimator（同一 StylePack 参数源：压深 8px / 回弹 120ms back）。

### 10.2 交付格式（资产管线交接）

- 目录：`src/BongoCat.App/assets/species/agua/{style}/{body,pawL,pawR}.png`
  （6 风格 × 3 件 = 18 张；440×360 @2x 精度，渲染时缩放 220×180 逻辑）；
- 锚点：同目录 `anchors.json`——`styles.{style}.pawAxisL/pawAxisR`（爪旋转轴，爪根处）
  + `hatAnchor`（头顶帽锚），**全部为 220×180 逻辑坐标**（渲染端 + (10,10) 映射进 240×200 画布）；
- 嵌入资源：csproj `EmbeddedResource Include="assets\species\agua\**"`（**必须**，散文件不入运行时）；
- 缺文件 / anchors 解析失败 → 该物种回退 cat 渲染 + 日志，**绝不崩溃**（渲染器防御，非美术侧职责）；
- 新增 sprite 物种的落位清单：资产目录 + anchors.json + species.json 加 `kind:"sprite"` 条目 +
  `SpriteSpeciesCatalog.DefaultSpriteSpeciesId` 扩展 + StyleRenderer/窗口侧物种白名单各一处。

### 10.4 已知瑕疵（V1 验收基线，220×180 显示尺寸下可容忍）

1. **鼓区修补痕迹**：原图成鼓被擦除后以"左右腿色水平合拢 + 上缘肚色垂直延伸"修补，
   两鼓之间的敞开区（逻辑 x82-138）可见竖向色带（黏土/纸面轻噪声掩盖，线稿风格最明显）；
2. **爪图边缘残片**：爪与原图鼓面重叠处随爪层保留（羽化 5px 渐隐），落点与程序化鼓面重叠后不显；
3. **剪纸风投影丢失**：papercut 背景浅投影随抠图清除（投影与背景色连续，无法分离），
   保留剪纸白纸边作为风格特征；
4. **clay 爪尖指向两鼓之间**：黏土原图爪位于双鼓上方两侧，程序化鼓布局更宽，敲击时爪尖落在鼓间身体上；
5. **贴纸/剪纸 bbox 含纸边**：sticker/papercut 的 bbox 底缘含白色纸边"裙边"，角色整体略高于矢量物种。
