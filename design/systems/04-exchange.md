# GDD-04 兑换合成（Exchange）

## 1. 概述
把多余的低阶物品合成为高阶物品的微决策系统：**同品质任意 3 件 → 随机 1 件下一品质**（不可指定结果）。它是挂机掉落与宝箱之间的"转化器"，让重复品和低保底物品始终有用。

## 2. 目标
- 为"非酋路线"提供确定性保底路径：纯合成路线首件 epic ≤ 10 天（与宝箱路线并行互补）。
- 合成是**金币零成本**的（消耗物品即成本），保持"挂机也能全收集"的支柱承诺。
- 单次合成操作 ≤ 3 次点击（选品质 → 选 3 件 → 确认），并提供"自动选取重复品"一键填充。

## 3. 输入
- 库存中同品质、同槽位可合成候选（规则见下）。
- 玩家操作：选择品质 → 填充 3 件（手动或一键重复品）→ 确认合成。
- 设置项：自动兑换开关（AutoExchange：重复品达到 3 件且该品质未集齐时自动合成）。

## 4. 输出
- 库存变更（-3 件 → +1 件新品质随机物品）。
- 合成动画与音效（猫爪拍鼓三连 → 光效出物品）。
- 图鉴更新事件（若为新物品）；重复则按 02 规则自动折算金币。

## 5. 规则
- **合式性校验**：3 件必须 (a) 同品质，(b) 品质 < legendary（legendary 3 件 → unique，是唯一 unique 获取途径），(c) 非装备中，(d) 允许跨槽位类型混合（帽子+皮肤+鼓 也可合，结果槽位类型随机）——**建议 V1 限制为同槽位类型合成**（结果类型 = 输入类型，更可控），跨类型合成留作 V2 开关。
- **结果随机**：从目标品质的全物品池等权随机（已拥有的也在池内 → 重复折金币，即合成的隐性成本）。
- **自动兑换（AutoExchange）**：默认关闭。开启后仅当"该品质图鉴未集齐且重复品 ≥ 3"时后台自动合成，动画静默，结果入气泡公告。
- ** legendary→unique 合成**：需要 3 件不同 legendary 物品（不允许 3 件同名），强化"收集广度"目标。

## 6. 数值框架
| 参数 | 默认值 | 说明 |
|---|---|---|
| 合成数量 | 3 → 1 | 固定，不可调 |
| 结果等权 | true | 目标品质池内等权 |
| 合成方向 | 仅向上 | 不提供降阶拆散 |
| 隐性重复率 | 依图鉴进度 | 合成期望成本 = 3×拆解价(n) vs 产出拆解价(n+1) |

**经济闭环校验**（用 02 的拆解价）：common 路线 3×10=30 → uncommon(40)：**1.33 倍增值**；uncommon 3×40=120 → rare(150)：1.25 倍；rare 3×150=450 → epic(600)：1.33 倍；epic 3×600=1800 → legendary(2500)：1.39 倍。增值率始终在 1.2–1.4 之间，既优于拆解（激励合成）又受结果随机稀释（纯金币视角不构成无限套利：合成不可逆、结果不可选）。与宝箱路线对比：27 个 common ≈ 9 天挂机 ≈ epic，与宝箱路线 3 天并行，合成略慢但零金币成本 ✓。

## 7. 边界情况
- **合成中途退出/崩溃**：合成事务原子化（先扣后加，写入流水；崩溃恢复时按流水回滚未完成事务）。
- **3 件同名 legendary 不允许**（unique 规则）→ UI 提示"需要 3 件不同的传说物品"。
- **品质池为空**（如某品质物品尚未实装）→ 该品质合成入口置灰并提示"暂无该品质物品"。
- **自动兑换与新物品惊喜冲突**：AutoExchange 产生的稀有结果同样播放全屏公告（不打折惊喜感）。
- **批量合成卡死**：一键"合成全部重复"每批 ≤ 20 次事务，异步执行，进度条可取消（取消在下一批边界生效，不回滚已完成批次）。

## 8. 开放问题
1. 合成结果是否排除"本次输入中包含的物品 id"？建议排除（防止 3 顶帽子合出同一顶帽子的挫败）。
2. 是否提供"定向合成"（花金币锁定结果类型/系列）？建议 V2 再议，V1 保持纯随机。
3. unique 合成是否需要额外金币费用（如 5000）来延长追逐？建议不加——3 件 legendary 本身已足够昂贵。
