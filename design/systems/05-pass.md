# GDD-05 通行证赛季（Season Pass）

## 1. 概述
本地驱动的赛季系统：赛季由 `seasons/<id>.json` 配置文件定义（可随版本热更），玩家通过敲击量与每日任务获得通行证 XP，升级解锁免费轨与高级轨奖励。无真实货币；高级轨用金币解锁，保留目标感且符合"无内购"铁律。

## 2. 目标
- 普通玩家（日均 350 金币当量的在线时长）一个赛季（42 天）能到达 **30–40 级**（免费轨主线奖励基本拿完）。
- 重度玩家（日均 4 倍时长）可达 **50 级满级**，溢出 XP 转金币。
- 赛季切换零人工干预：日期判定 + 配置文件自动装载；往期赛季可回看领取状态。

## 3. 输入
- `OnKeystrokeCount(n)` 与经济事件（宝箱开启、合成、装备变更）。
- 系统当前日期（赛季窗口判定）。
- `seasons/season_001.json`（赛季配置）。
- 玩家操作：领取里程碑奖励 / 解锁高级轨。

## 4. 输出
- 通行证 XP 与等级；里程碑奖励发放（金币/物品/消耗品/独占称号）。
- 领取气泡（猫头顶冒出奖励图标，对应原作里程碑气泡机制的原创实现）。
- `pass_progress.json` 持久化（当前赛季进度 + 往期赛季归档）。

## 5. 规则
- **赛季窗口**：`startDate` ~ `endDate`（含当日）；窗口外该赛季配置不激活；无激活赛季时通行证 UI 隐藏（不做"填空赛季"）。
- **XP 来源**：
  - 敲击：每 1000 次有效敲击 = 10 XP（受 02 的防刷判定约束）。
  - 每日任务（3 条/日，从赛季配置池轮换）：如"开启 2 个宝箱 +30 XP""累计敲击 3000 次 +20 XP""合成 1 次 +25 XP"。每日 0 点重置，未完成不累积。
- **等级曲线**：每级需求 = 100 + (level-1) × 10 XP（线性微增）。
- **双轨奖励**：每级 1 个免费奖励 + 1 个高级奖励；高级轨需金币一次性解锁（2500 金币 ≈ 1 周积蓄）。
- **奖励发放**：手动领取（里程碑气泡），赛季结束后 7 天宽限期可补领，之后过期（过期不发补偿，UI 明示倒计时）。
- **赛季结算**：XP 清零；**奖励未领的按宽限规则处理；金币与物品资产永不清空**（收集是永久资产）。
- **防刷**：XP 与经济共用敲击有效性判定；每日 XP 上限 300。

## 6. 数值框架
| 参数 | 默认值 | 说明 |
|---|---|---|
| 赛季时长 | 42 天 | 配置可调 |
| 满级 | 50 | |
| 每级 XP | 100 + (level-1)×10 | |
| 敲击 XP | 10 XP / 1000 键 | 每日上限 300 XP |
| 高级轨解锁 | 2500 金币 | 一次性 |

### 满级时间验算
30 级累计 XP = Σ(100+(n-1)×10) ≈ 7,350 XP。普通玩家 XP 日收入 ≈ 敲击 14400 键 = 144（上限内）+ 任务 ~75 = **~220 XP/日** → 33 天达 30 级 ✓；重度玩家 ~500 XP/日（含上限）→ 42 天内满级 ✓。

## 7. 边界情况
- **跨天任务未领**：任务 XP 自动在完成时入账（无需手动领任务），仅奖励需手动领。
- **赛季切换瞬间在线**：切换在次日 0 点惰性触发（不热切换打断会话）；切换时弹一次性公告。
- **配置文件缺失/损坏**：赛季 UI 显示"暂无赛季"；进度文件保留不删。
- **系统时间回拨**：以流水最新时间戳为下界，日期早于下界视为异常，XP 结算冻结当日。
- **宽限期内游戏未启动**：宽限期按墙钟计，错过即过期（诚实设计，不追补）。
- **离线期间错过整赛季**：往期归档只读，不提供补跑。
