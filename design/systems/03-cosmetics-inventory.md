# GDD-03 装扮槽位 / 库存 / 图鉴 / 预设

## 1. 概述
收集元游戏的呈现层：物品分 6 个槽位类型，玩家在库存中查看、装备、拆解；图鉴（Collectopedia，原创命名）展示全收集索引与完成度；预设将整套装扮保存为可一键切换的方案。

## 2. 目标
- 装备任意物品 → 猫渲染层更新 **< 100ms**，即时可见。
- 图鉴是"长期目标看板"：完成度百分比 + 缺口指引，玩家随时知道下一个目标。
- 预设切换一键完成（含音效反馈），支持 8 个以上预设槽。

## 3. 输入
- 库存数据（物品实例：`{itemId, quality, acquiredAt, source}`）。
- 玩家操作：装备/卸下/拆解/保存预设/应用预设/重命名预设。
- 宝箱开启与挂机掉落事件（新增物品推送入库）。

## 4. 输出
- 猫渲染层逐层替换指令（body / leftPaw / rightPaw / hat / bongos，映射见规则）。
- 图鉴状态（每物品：已拥有/未拥有 + 品质最高记录 + 收集进度分类）。
- 预设文件 `presets.json` 持久化。
- 装备变更事件（供多人模式同步与赛季任务判定）。

## 5. 规则
- **槽位类型**（每类同时只能装备一件）：
  | 槽位 | 说明 | 渲染层 |
  |---|---|---|
  | skin | 猫皮肤（含身体+双爪整套） | body + leftPaw + rightPaw |
  | hat | 帽子/头饰 | hat |
  | bongos | 鼓外观（含敲击音色变体） | bongos |
  | emote | 表情包（按键触发的喷发粒子图） | 特效层 |
  | uitheme | UI 主题（菜单配色/边框） | 非猫层 |
  | consumable | 消耗品（临时 buff：如 30min 金币+10%） | 无渲染，库存结算 |
- **品质即独立物品**：同一形象按品质区分（如"贝雷帽"有 uncommon 与 rare 两个版本，视觉可同源不同配色），品质决定拆解价与收集难度。
- **装备规则**：槽位互斥；装备中物品不可拆解；卸下后恢复默认（原创基础皮肤）。
- **图鉴规则**：按系列（CollectionNames 原创系列：如"工作日系列""像素复古系列""节日系列"）分组；每系列显示 n/m 完成度；全系列完成给予专属奖励（金币 + 独占称号，不做 unique 物品强绑定以免死锁）。
- **预设规则**：预设 = 6 槽位的物品引用快照；应用预设 = 批量装备；消耗品槽在预设中记录但应用时不自动消耗。
- **多显示器/窗口状态无关**：装扮渲染与 01-cat-core 解耦，仅通过渲染层接口通信。

## 6. 数值框架
| 参数 | 默认值 | 说明 |
|---|---|---|
| 预设槽位数 | 8 | 上限 16 |
| V1 物品总数 | ~60 | skin×12 / hat×20 / bongos×10 / emote×8 / uitheme×6 / consumable×4 |
| 品质分布目标 | C 40% / U 27% / R 18% / E 10% / L 4% / U(nique) 1% | 每系列内部大致遵循 |
| 图鉴完成奖励 | 每系列 200–1000 金币 | 全收集额外 5000 + 独占称号 |
| consumable buff | 金币 +10%，持续 30min | 不叠加，同时仅一个 |

物品数据全部由 `items.json` 驱动（id、名称、槽位、品质、渲染引用、系列、描述文案），程序不硬编码。

## 7. 边界情况
- **装备物品被拆解/合成消耗**：装备中物品禁拆（规则 5）；合成只允许选非装备中物品（见 04）。
- **存档损坏/物品 id 失效**：加载时逐条校验 `items.json`；失效引用置为"缺失物品"占位并卸下，不崩溃。
- **预设引用物品已不存在**：应用时跳过该槽并提示；不回滚其余槽位。
- **重复物品上限**：同物品同品质最多持有 9 件，超出第 10 件自动折算金币（防库存膨胀与合成刷币）。
- **图鉴未获得物品显示**：显示剪影 + 名称打码（"？？？系列·帽子"），保留发现惊喜；已获得显示全信息。
- **consumable 到期时正开着菜单**：到期结算以时间戳为准，UI 下次刷新更新显示。

## 8. 开放问题
1. 猫皮肤是否改变体型（如胖猫/长猫）还是仅配色花纹？影响素材工作量，建议 V1 仅配色+花纹。
2. bongos 音色变体是否随品质改变音质（L 品质用更丰富采样）？建议是，成本低、价值感强。
3. 表情触发方式：固定热键（如 Ctrl+1~4）还是点击托盘菜单？建议两者都支持。
