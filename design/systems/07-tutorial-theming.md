# GDD-07 教程引导 + UI 主题

## 1. 概述
两类"体验修饰"系统合并一篇：**教程**确保新玩家 60 秒内理解核心循环（敲击 → 掉落 → 开箱 → 换装）；**UI 主题**是 uitheme 槽位的物品化呈现（菜单配色/边框/点缀物，作为收集品的一部分）。

## 2. 目标
- 教程：**≤ 3 步、≤ 60 秒、随时可跳过**，完成率目标 > 90%。
- 教程完成后永不打扰（除非玩家从设置主动重看）。
- UI 主题：换主题 → 全菜单即时刷新（< 200ms），无需重启；主题含"角色化"元素（边框挂件、按钮猫爪形状）作为炫耀点。

## 3. 输入
- 首次启动检测（`tutorial_done` 标志）。
- 玩家操作：跳过/下一步/重看教程；装备 uitheme 物品。

## 4. 输出
- 教程覆盖层（半透明遮罩 + 高亮区域 + 步骤气泡）。
- 教程完成事件（触发 05 的任务判定与奖励）。
- WPF 资源字典（ResourceDictionary）动态替换：颜色、画刷、控件模板引用。

## 5. 规则
### 教程（3 步）
1. **"按任意键！"**——遮罩留出猫的位置，等待玩家敲 5 次；猫敲击即教程反馈（自解释设计，无文字墙）。
2. **"金币来了"**——模拟/加速一次掉落气泡 → 指向金币余额与商店入口。
3. **"给它戴上"**——打开装扮菜单，引导装备开局赠送的 1 顶 common 帽子（开局发放由经济系统保证）。
- 跳过按钮常驻右下角；跳过即标记 `tutorial_done` 并补发赠送帽。
- 每步可前进条件宽松（第 1 步敲任意 5 键即可），无失败状态。

### UI 主题
- 主题物品定义：`uitheme` 槽位物品，数据含主色/强调色/背景色/边框样式引用/可选点缀精灵。
- 装备主题 = 替换 ResourceDictionary；默认主题随程序内置，不可卸下只能更换。
- 主题**不影响**猫本体渲染（那是 skin 槽位职责），只影响菜单/弹窗/气泡。
- 主题在多人模式下仅影响本机 UI（远端猫不受影响）。

## 6. 数值框架
| 参数 | 默认值 | 说明 |
|---|---|---|
| 教程步数 | 3 | 上限 4 |
| 开局赠送 | 1×common 帽 + 150 金币 | 保证第 3 步可执行 |
| V1 主题物品数 | 6 | 品质分布 C2/U2/R1/E1 |
| 主题切换耗时 | < 200ms | 资源字典热替换 |
| 教程气泡停留 | 无超时 | 等待玩家操作 |

主题配置 JSON 示例（`items.json` 内 uitheme 条目）：
```json
{
  "id": "theme_midnight_paw",
  "name": "午夜猫爪",
  "slot": "uitheme",
  "quality": "rare",
  "colors": { "primary": "#2B2D42", "accent": "#F0567A", "background": "#1A1B26", "text": "#EAEAEA" },
  "borderStyle": "roundedPaw",
  "decalSprite": "ui_decal_pawprint"
}
```

## 7. 边界情况
- **教程期间掉落/宝箱事件触发**：教程遮罩为非模态，掉落气泡照常出现（反而是正反馈）；教程步骤不与掉落抢焦点。
- **教程中退出/崩溃**：按步骤粒度存进度，重启从当前步续；跳过标志优先于进度。
- **主题资源缺失/损坏**：校验失败回退默认主题并记日志，不白屏。
- **颜色可读性**：所有主题色组合强制通过对比度检查（正文 ≥ 4.5:1，WCAG AA，对齐可访问性要求）；不达标主题在内容管线期打回，不放行。
- **高 DPI / 缩放**：教程高亮区域按 DPI 缩放计算；125%/150% 缩放下气泡不错位。
- **玩家在教程前就自己开箱**：第 2/3 步的条件检查先行跳过已满足的步骤（幂等）。

## 8. 开放问题
1. 教程是否需要语音/音效引导？建议仅轻音效（步骤切换叮一声），不做语音。
2. UI 主题是否改变菜单布局（大改版主题）？建议 V1 仅换肤不改布局，模板级主题 V2 再议。
3. 色弱模式：是否提供独立于主题的高对比开关？建议在设置中提供（与主题叠加生效），需可访问性评审确认。
