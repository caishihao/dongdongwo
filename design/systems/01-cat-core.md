# GDD-01 桌宠核心（Cat Core）

## 1. 概述
桌宠核心是产品的"玩法本体"：透明置顶窗口中渲染一只原创猫，全局键盘钩子捕获任意按键，猫的左右爪交替敲击面前的鼓，并播放鼓点音效。所有元游戏（经济/装扮/赛季）都挂载在此之上。

## 2. 目标
- 任意按键 → 视觉+听觉反馈延迟 **P95 ≤ 50ms**（钩子回调到渲染帧提交）。
- 空闲 CPU 占用 **< 1%**（自适应轮询降频）；内存 < 120MB。
- 窗口对用户正常桌面操作**零干扰**：不抢焦点、不可点击命中（除拖动模式）、穿透鼠标。
- 崩溃/重启后位置、装扮、设置完整还原。

## 3. 输入
| 输入 | 来源 | 说明 |
|---|---|---|
| 按键事件 | Win32 低级键盘钩子（WH_KEYBOARD_LL） | 任意键按下即触发；忽略程序自身窗口的按键 |
| 鼠标拖动 | 托盘菜单"移动模式"或 Ctrl+Alt+拖动 | 拖动期间窗口临时可命中 |
| 托盘菜单 | NotifyIcon | 打开装扮/设置/退出/移动模式 |
| 设置项 | settings.json | 音量、敲击回弹时长、轮询间隔、开机自启、主屏选择 |

> 钩子实现注意：回调内不做重活，入队后由 UI 线程消费，防止系统移除钩子。

## 4. 输出
- 猫渲染帧（身体/左爪/右爪/帽/鼓 五层独立位图，支持逐层替换=装扮系统接口）。
- 鼓点音效播放（左爪=低音，右爪=高音，各 2-3 变体随机轮换）。
- 事件流（供上层系统订阅）：`OnTap(side, virtualKey, timestamp)`、`OnKeystrokeCount(n)`、`OnDragEnd(x,y)`。
- 持久化：位置（相对屏幕比例）、设置、敲击总计数（供经济系统）。

## 5. 规则
- **交替规则**：维护 `nextSide`，每次 Tap 输出 `nextSide` 并翻转。连续按键间隔 < 30ms 时不翻面（防钩子重复事件）。
- **动画规则**：爪子状态机 `Idle → Down(0ms 即落) → Up(回弹 reboundMs)`。回弹期间再次按键允许打断（直接再落），不做动画排队——手感优先。
- **呼吸浮动**：Idle 时身体 y 轴 sin 波动（周期 ~2.4s，幅度 ~2% 身高），可在设置关闭。
- **镜像**：提供整体水平镜像选项（纯视觉）。
- **拖动**：进入移动模式后跟随鼠标；结束时做越界修正（保留 ≥60% 身体在任一监视器内，否则回中）。
- **位置记忆**：存 `(x / screenW, y / screenH, monitorDeviceName)`，跨分辨率还原；主屏变更（Win+Shift+方向）后 clamp 到新屏。
- **多监视器**：托盘菜单可切换所在屏；默认屏 = 主屏。

## 6. 数值框架
| 参数 | 默认值 | 单位 | 可调范围 |
|---|---|---|---|
| reboundMs | 120 | ms | 80–200 |
| activePollIntervalMs | 10 | ms | 5–30 |
| idlePollIntervalMs | 100 | ms | 50–250 |
| idleAfterSeconds | 15 | s | 5–60 |
| debounceMs | 30 | ms | 20–50 |
| bobbingPeriod | 2.4 | s | 固定 |
| bobbingAmp | 0.02 | 身高比例 | 固定 |

自适应轮询：持续 `idleAfterSeconds` 无按键 → 切 idle 间隔；任意按键 → 立即切回 active。

## 7. 边界情况
- **钩子失效/被安全软件拦截**：检测 `SetWindowsHookEx` 返回 0 或连续 10s 无任何钩子回调 → 托盘气泡提示 + 引导"以管理员或允许钩子权限"重试。
- **系统 UAC 提权窗口聚焦**：低级钩子收不到按键（预期行为），猫保持 idle；不报错、不打扰。
- **DWM 禁用/远程桌面**：AllowsTransparency 失败 → 回退色键透明（默认品红 #FF00FF 抠色），同原作机制的思路但自实现。
- **显示器拔出**：位置还原时屏不存在 → 按剩余屏枚举 clamp；全部丢失 → 回主屏中心。
- **锁屏/待机恢复**：恢复后强制一次位置校验与 idle 状态重置；敲击计数按墙钟间隔 > 10min 则视为离线时段（经济不结算，见 02）。
- **高频连打（按住键重复）**：debounceMs 去重；按住不放只算一次。
- **游戏全屏独占模式**：猫被覆盖，属预期；托盘提供"暂停渲染"选项。
